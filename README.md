# 海龟汤插件 (astrbot_plugin_soup_tantan)

这是一个为 **AstrBot** 框架打造的海龟汤推理游戏插件，支持从外部 API 获取题库并结合大语言模型（LLM）作为智能裁判，支持汤品分类与篇幅选择，让群聊充满悬疑与推理的乐趣。

## ✨ 功能特性

- **多模式题目分类**：支持清汤（搞笑）、红汤（惊悚）、黑汤（暗黑）、甜汤（温馨）。
- **篇幅自选**：可按需选择长篇、中篇、短篇的题目。
- **智能裁判**：集成 LLM 大模型（可选），自动识别玩家提问并回应（是/否/不重要/是也不是）。
- **完全解耦设计**：支持通过配置系统动态指定私有海龟汤 API 和鉴权令牌。
- **本地降级方案**：若未配置外部 API，自动启用内置的测试题目。

## 📦 安装与配置

将本插件放置在 AstrBot 的插件目录中，或者通过插件市场/源码安装。

### 配置说明

在安装好插件后，你可以在 AstrBot 控制面板或者直接修改插件目录下的 `config.json` 文件来设置以下参数：

- `api_url`: 海龟汤服务 API 地址（默认推荐公共接口：`http://hgt.tsc-mc.cn/api/soup`），若留空将使用内置测试题目。
- `api_token`: API 的鉴权令牌（Bearer Token）。
  > **💡 获取 Token 提示**：若使用默认推荐接口，请前往 [https://hgt.tsc-mc.cn]进行注册以获取您的鉴权 Token，注册时使用邀请码：`f8066708e692154f`。
- `judge_llm_provider`: 指定用于裁判提问的 LLM 提供商 ID，若留空则自动使用框架当前启用的默认模型。
- `game_timeout`: 一局游戏无操作的超时时间，默认为 300 秒。

## 🎮 指令列表

| 指令 | 描述 |
| :--- | :--- |
| `/汤 <分类> <篇幅>` | 开始一局游戏。示例：`/汤 红汤 短`。如果不带参数将随机出题。 |
| `/汤 help` | 显示帮助菜单 |
| `/汤状态` | 查看当前题面及提问次数统计 |
| `/验证 <推理>` | 提交最终推理，如果完全还原或核心逻辑对，将宣布胜利并揭晓答案 |
| `/揭晓` | 立即结束当前游戏，并显示汤底 |
| `/提示` | 让裁判给出一条方向性的思路提示 |
| `/查看` | 查阅当前本局游戏所有的问题与答案记录 |
| `/提问+<内容>` | 向汤面提问的快捷命令。也可以直接在群里 `@机器人 你的问题` |
